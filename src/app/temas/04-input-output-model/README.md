# 04 — input / output / model

APIs modernas signal-based para comunicación entre componentes.

## Ejemplo con Persona

- `input()` recibe la persona
- `model()` edita el nombre en two-way
- `output()` emite la persona seleccionada

## Preguntas típicas

- Diferencia `@Input()` vs `input()`
- Qué problema resuelve `model()` vs `[(ngModel)]` en componentes
- `input.required()` vs valor por defecto
